oro

Criação, inicialização e padronização de projetos de software.

Install

$ curl -fsSL https://willsantos.github.io/orotools/install.sh | bash

Detecta SO e arquitetura, valida o checksum sha256 e instala em ~/.local/bin. Já tem o oro? oro upgrade atualiza.

Baixar Todas as releases

Sem JavaScript ou SO diferente? Baixe o asset certo na página de releases.

Quick start

$ oro new meu-app --stack fastify-next --yes

Stacks oficiais: dotnet, dotnet-next, fastify-next, rails. Adote um repositório existente com oro init.
