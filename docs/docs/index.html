OroTools

O que é​

OroTools é a CLI oro: criação, inicialização e padronização de projetos de software a partir de recipes — YAML que declara variáveis, steps de arquivos, skills, agents e pipeline de CI.

  • Scaffold reproducível — oro new gera o projeto inteiro a partir de uma recipe oficial ou customizada.
  • Adoção de projetos existentes — oro init detecta a stack e gera o manifest; oro apply reconcilia de forma idempotente.
  • Skills de IA gerenciadas — oro skills instala/atualiza skills com lock versionável.
  • Dev manager — oro dev gerencia os dev servers dos seus projetos em um só lugar.

Quick start​

Instalar:

curl -fsSL https://orotools.willsantos.dev/install.sh | bash

Criar um projeto a partir de uma stack oficial:

oro new meu-app --stack fastify-next --yes
cd meu-app
oro info

Ver o plano sem executar nada:

oro new meu-app --stack dotnet-next --dry-run

Adotar um repositório existente:

cd projeto-existente
oro init
oro doctor --stack rails

Comandos​

ComandoDescrição
oro newCria projeto a partir de uma recipe
oro applyReconcilia o projeto com o manifest e a recipe
oro initDetecta a stack do diretório atual e gera orotools.yaml
oro doctorValida requirements (ferramentas/versões) da recipe
oro infoMostra o estado do manifest do projeto
oro addRegistra entrada no manifest
oro recipe listLista recipes oficiais embutidas
oro skillsInstala skills da recipe e do catálogo (wizard)
oro devGerencia dev servers (list/status/start/stop/logs/open/add)
oro upgradeAtualiza o oro para a última release

Use oro [comando] --help para flags e detalhes de cada comando.

Por onde continuar​

  • Instalação — install.sh, versão específica, oro upgrade, build from source.
  • Receitas — stacks oficiais e recipes customizadas.
  • Manifest — o orotools.yaml como fonte de verdade do projeto.
  • Arquitetura — como os subsistemas da CLI se encaixam.
